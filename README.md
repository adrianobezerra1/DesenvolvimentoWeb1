# Desenvolvimento Web 1
 
Repositório da disciplina de Desenvolvimento Web 1 do curso de Sistemas para Internet — Fatec Lins.
 
## Estrutura do repositório
 
```
DesenvolvimentoWeb1/
├── 2026/
    ├── aulas/          ← Códigos desenvolvidos durante as aulas
    └── Extensao/       ← Projetos de extensão dos alunos
```
 
### 📁 aulas/
 
Contém todo o código-fonte produzido durante as aulas ao longo do semestre. O material está organizado por aula ou tema, servindo como referência de estudo para os alunos.
 
### 📁 Extensao/
 
Contém os projetos de extensão desenvolvidos pelos alunos. Cada subpasta corresponde a um grupo e inclui todas as etapas do projeto: pesquisa, análise de UX/UI, wireframe e código HTML/CSS do site estático.
 
## Sobre a disciplina
 
A disciplina de Desenvolvimento Web 1 apresenta os fundamentos do desenvolvimento de páginas web, com foco em HTML semântico e CSS. Os alunos aplicam os conhecimentos adquiridos em um projeto prático de extensão, desenvolvendo um site estático para uma ONG de proteção e adoção de animais.
